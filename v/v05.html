It detects the lesion. It cannot localize it.

Text-conditioned 3D medical models collapse to oversized, imprecise regions the moment a lesion is small. Everything below is the session that found out why.

~/lesion-grounding main $ eval --dataset brats2020 --split held-out --group-by lesion-size

loading 73 volumes @ 128^3 ......... ok
region              large    medium     small      ratio
------------------------------------------------------
whole tumour        0.281     0.137     0.057    4.9x
tumour core         0.176     0.059     0.019    9.3x
enhancing tumour    0.149     0.037     0.010   14.9x
monotonic in lesion size for every region.

~/lesion-grounding main $ eval --model unet-supervised # is the signal even there?

supervised U-Net, same lesions ........ degradation 1.2x
PASS  small lesions are learnable.
      so the degradation is not the data. it is the conditioning.

~/lesion-grounding main $ ablate --text-encoder random-vectors

swapping PubMedBERT -> random gaussian vectors
delta Dice ............................ ~0.000
FAIL  the language contributes nothing measurable.
      the query is an opaque class identifier that happens to be
      spelled in English.

~/lesion-grounding main $ patch --list --sort-by gain

  x size-conditioned prompting ........ helps small, breaks large
  x multi-scale ensembling ........... gains core, loses enhancing
  x scale-matched retraining ......... overfits its own tercile
  ✓ centre-weighted window blending ... +0.145 Dice, no retraining
the cheapest patch on the list beat every elaborate one.

~/lesion-grounding main $ patch --apply centre-weighted && eval --region ET --size small

small enhancing tumour, patients with non-zero Dice
  before ....... 0 / 21
  after ........ 7 / 21
no weights were modified. the fix is in how windows are merged.

~/lesion-grounding main $ stats --paired-wilcoxon --correct bh --replicate 3

171 paired tests, Benjamini-Hochberg corrected
replication across three independent splits ... 9 / 9
PASS  the failure reproduces.
