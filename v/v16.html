What the nine cells add up to

The target shrinks. The guess does not.

Localization declines monotonically with lesion size in all three regions and never recovers. Detection is unaffected throughout, which is what makes a single aggregate number so misleading here.

A plain supervised U-Net on the same small lesions degrades 1.2× against 14.9×, so the lesions are learnable and the conditioning is what fails. Replacing PubMedBERT with random vectors changes almost nothing: the query is an opaque class identifier that happens to be spelled in English.

What was left was the plumbing. The volume is traversed in overlapping sliding windows merged by flat average, which smears a small lesion across everything near a window edge. Weighting each window toward its own centre gives +0.145 Dice with no retraining and recovers small enhancing tumour in 7 of 21 patients.

Three more elaborate interventions were tried first and each was reversed after a control caught the error. A shared confound is not a cancelled confound.
