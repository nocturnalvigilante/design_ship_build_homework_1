Session 1 · Medical imaging

The headline feature never shipped working.

Text-conditioned 3D models detect that a tumour is present, then return a region many times too large and centred somewhere else. The smaller the lesion, the wider the miss.

Contribution from the language

Swap PubMedBERT for random vectors and nothing moves. The query is an opaque class identifier spelled in English.

The fix

One line in the merge step. No retraining.

The volume is traversed in overlapping sliding windows merged by flat average, which smears a small lesion across everything near a window edge. +0.145 Dice, and not one weight modified.

# before: flat average
acc += logits
cnt += 1

# after: centre-weighted
w    = gaussian(win_shape)
acc += logits * w
cnt += w

One more thing

A shared confound is not a cancelled confound.

The fault was not in the model and not in the language. It sat in the inference plumbing, where nobody was looking.

Every stage of a pipeline is an instrument until somebody measures it.
