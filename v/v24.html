About this work

Asked whether a tumour is present, the model answers correctly. Asked where it is, it returns a region many times too large and centred somewhere else — and the smaller the lesion, the wider it misses.

Localization declines monotonically with lesion size in every region and does not recover. For enhancing tumour, the smallest and most clinically specific region, performance falls 14.9× from the largest size tercile to the smallest. Detection is unaffected throughout, which is precisely what makes a single aggregate score misleading here.

Four explanations were examined in turn. Three were set aside.

I

That small lesions are simply unfindable

A plain supervised network, given the same lesions with no language anywhere in the pipeline, degrades only slightly. The lesions are learnable.

Set aside1.2×

II

That the text encoder is too weak

Replacing the domain encoder with random vectors changes almost nothing. The query functions as an opaque class identifier that happens to be spelled in English.

Set asideΔ ≈ 0

III

That the model must be told the lesion is small

Size-conditioned prompting, multi-scale ensembling and scale-matched retraining each traded one failure for another and were reversed under control.

Set aside3 of 3

IV

That the sliding windows are merged badly

Flat averaging disperses a small lesion across every window that overlaps it. Weighting each window toward its own centre recovers small enhancing tumour in 7 of 21 patients, with no retraining and no modified weights.

In closing

A shared confound is not a cancelled confound.

The fault was not in the model and not in the language. It sat in the inference plumbing, in a stage nobody had thought to inspect, and the repair costs nothing at all.

Every stage of a pipeline is an instrument until somebody measures it.
